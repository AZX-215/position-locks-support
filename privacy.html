Position Locks Privacy Policy

Position Locks changes position lock settings for nodes in an editable Katapult Maps job when you request an update.

Job data used

On supported Katapult Maps pages, the extension reads job and node identifiers, node types, position lock states, map coordinates, visible node information, related connection identifiers, and node attributes. Attributes can include pole tags, addresses, or notes entered in the job. The extension uses this data to find eligible nodes, identify the selected node, verify a lock change, and detect unexpected changes to the node.

Local recovery record

Before changing a node, the extension stores a recovery record in the browser's Katapult site storage. The record includes the job and node identifiers, original type and lock state, requested lock state, coordinates, search identifiers, and a snapshot of other attributes and connection references. The record is cleared after a verified edit or recovery. An interrupted edit may leave this record on the device until a recovery succeeds or the site's storage is cleared.

Transfers and sharing

Katapult saves requested changes through its native editor and normal service under your existing account. The extension sends no job data to the extension developer or a separate extension server. It has no analytics, advertising, or telemetry and does not sell job data.

Limited use

The extension's use of job data adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Contact

For questions about this policy, open a GitHub support issue. Do not include private job data.
