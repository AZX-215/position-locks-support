Support

Get help with node selection, batches, and interrupted edits in Position Locks.

Using Position Locks

  • Single Node. Select a supported node on the map and open Node Info. The panel shows that node’s current lock status.
  • All Job Nodes. Lock or unlock eligible poles, references, building attachments, and break points in the current job. The panel shows the eligible and locked totals.
  • Interrupted edit. Reopen the same job on the same Katapult site and in the same Chrome profile. If Restore Node Type appears, select it and check the reported lock status and any warning before continuing.

If a batch stops, completed changes stay saved. Check the summary and address any reported error before starting another batch.

Report an issue

Include the following in your report.

  • Your Position Locks version
  • The mode you were using, Single Node or All Job Nodes
  • The action you ran and the steps to reproduce the issue
  • What you expected and what happened, including the error text with job and node identifiers removed

Use a demo job or redact private job details from screenshots and examples.
